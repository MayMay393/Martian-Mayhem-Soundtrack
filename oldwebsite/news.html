1/5/2023: News on the state of the game

Unfortunately, a lot has happened to Martian Mayhem since the past devlog. The version I have developed from January to March has been cancelled, and I've been crafting a new version of this game ever since.
It's going to use the same soundtrack as the old game, and all mechanics from the old version will be in this game too. (Additionally with an improved inventory system, improved lighting, and more awesome improvements!)
The first beta version of this game will include most of these new features but the 1.0.0 version will have a lot of content.

4/7/2022: 1.1 News

Hi! 1.1 has been delayed until Summer 2022. Things have been going on in my life so I need a break from game development, so I hope you understand.


3/30/2022: 1.0.1 Bugfix

Hello! Martian Mayhem is finally out, for real now. I've fixed all bugs I'm aware of and did some world generation altering.

3/4/2022: Devlog 5 + Game Delayed

Unfortunately, Martian Mayhem is getting delayed until early April (Lots of complicated stuff I gotta do before release.) I need just a little more time to work on the game, I just need to add a few more stuff and then polish the game's existing code. Anyways, I've added some really cool stuff since last devlog:

-Even more improved lighting.
-All tools added into the game.
-All armor added into the game.
-Enemy drops actually work now.
-Summoning items!
-Solar Boss
-Brand new builder mode with enhanced controls
-UI Improvements
-New "Insane World" generation. Might be included as a secret 4th game slot?
-New cave generation. Small caves, Large caves, chasms, and tunnels.
